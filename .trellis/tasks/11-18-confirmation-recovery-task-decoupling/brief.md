# Brief — 放宽后台确认的恢复输入与任务绑定限制

## Goal

- 让后台确认支持服务恢复和任务绑定差异，并修正会话身份误选。

## Scope

- 修复 Codex 与 Claude 环境变量共存时的身份解析。
- 移除 Brief、Check、Push 的材料任务与会话任务相等校验。
- 支持 Codex `daemon_recovery` 回合准备确认。
- 同步协议、规范、分发产物及回归测试。

## Non-Goals

- 软件发版、业务项目升级及截图中 findings 的修复留待后续安排。

## Technical Overview

- 按当前宿主选择身份；以材料声明任务确定确认范围；沿原生恢复关系衔接输入与当前展示回合。
- 保留完整展示后计时、新输入作废、材料变化作废、原窗口归属和单次领取。

## Context & Decisions

- 已复现继承的 Claude 标识被列表优先选中。
- 任务声明可以与准备时的会话绑定不同；等待期间绑定变化继续作废旧确认。

## Risks

- 恢复输入与展示回合的衔接需要覆盖连续恢复和插话。
- 材料生成方承担目标任务的准确性；共享身份解析需要跨平台回归。

## Acceptance

- 恢复回合完成准备、展示、等待、领取及 started。
- 空绑定和不同绑定均可按材料任务准备确认。
- 任务激活、查询与确认使用同一 Codex 身份。
- 受影响专项、完整回归、产物一致性及 Ubuntu/Windows CI 通过。

## Next Step

- 确认后激活任务，进入实现路由。
