# 支持原生 Windows 后台超时确认

## 目标

让原生 Windows 上普通启动的 Codex 与 Claude 可以使用后台超时确认，并保留会话归属、退出失效与单次执行保护。

## 需求与验收

- **R1**：两端在可核验会话中完成展示、等待、原生唤醒、领取和 started；无需 WSL 或额外常驻服务。
- **R2**：新消息、原窗口退出、恢复到新窗口、同一会话双开、伪造通知和重复领取有明确的取消或拒绝结果。只有可靠归属和来源齐全的会话进入自动路径。
- **R3**：提供真实 Windows Codex 和 Claude 的独立验收，覆盖普通启动、退出和同会话双开。原生 Windows Python 3.8/3.12 与 Linux/WSL 回归均有证据；夹具验证与真实宿主验收分别记录。
- **R4**：容量子任务已有的本地实现与验证作为联调基线。容量交付、Windows 新增差异和发布动作保持独立。

## 范围边界

用户要求先做 Windows 兼容并搁置 beta。本任务保留人工回退、默认倒计时、现有确认权限和发布边界。
