# 遥测第一批：平台活跃与核心操作质量

## Goal

让管理员从实际平台、持续使用和核心操作质量三个维度理解 Flower 的使用情况，形成 Flower CLI 与 ai-fund 接收、存储、展示的最小遥测闭环。

## Background

- 用户已选择第一批优先规划，并于 2026-09-06 确认首批实际会话平台覆盖 Claude Code 和 Codex；总体顺序见父任务 [roadmap.md](../09-05-telemetry-roadmap/roadmap.md)。
- 现有代码只有版本检查、初始化完成、升级完成事件，操作系统 `platform` 不能代表 AI 平台；现有设备最近上报时间无法还原历史每日活跃。
- 现有入口、数据结构与兼容依据见 [research.md](research.md)。字段和技术机制以 [design.md](design.md) 为准，执行顺序与验证见 [implement.md](implement.md)。用户已确认完整 Brief 并于 2026-09-06 开始实施；两仓本地实现与验证已完成，证据见 [check-report.md](check-report.md)。

## Requirements

- R1：实际会话采集覆盖当前 0.6 集成中的 Claude Code/Codex，普通 CLI 操作单独统计。已安装的平台不能当作实际使用平台，old/0.5 与其他 AI 平台不冒称具备新会话观测能力。
- R2：按安装实例和 UTC 日记录可观测活跃，展示日活、近 7/30 日活跃、首次 v2 观测趋势、7/30 日内回访。回访分别指首次有效活动后的第 1–7/1–30 天内至少再次活跃一次；观察窗结束并经过 72 小时补传宽限后才进入成熟队列。
- R3：记录初始化、项目升级、自更新、插件安装的终态、错误分类和耗时，支持按版本分析质量；无执行和内部嵌套不重复计数。
- R4：区分 CLI、捆绑 Trellis、项目 Trellis 和安装的 Skill Garden 版本；版本未知时保留空值。
- R5：用户级开关持续有效；普通 CLI 与 hook 静默；采集故障不能改变原输出和退出码。
- R6：在 ai-fund 现有管理员安装监控中增加平台、活跃与操作质量视图。
- R7：新统计明确展示采集开始时间与平台覆盖；旧客户端数据继续可读，不能补造历史活动或失败。
- R8：缺少开发者别名时仍可参与安装实例统计；耗时与成功率必须使用可解释的样本和分母。
- R9：成功率为成功 /（成功 + 失败），取消单列，无终态不推断；纯执行耗时与包含交互等待的耗时分别呈现，样本量为零时显示空态。
- R10：有效事实数据保留 180 天，首次 v2 观测锚点持续保留到设备删除；历史清理后不把老安装计为新安装。日活动与终态只含白名单元数据。
- R11：新采集使用现有用户级遥测总开关，默认行为延续；持久停用阻止新增/后续发送并清理未发送事件，环境变量临时停用保持零写入。普通命令与 hook 不等待遥测网络请求。
- R12：管理端提供使用概览、平台与版本、持续使用、操作质量四个区域；仅管理员可访问。采集和展示均属于第一批，不以客户端单独新增字段作为交付完成。

## Acceptance Criteria

- [x] A1（R1/R4）：安装平台不产生活跃，Claude/Codex 入口可准确归属；CLI 单列，各类版本按真实来源记录。
- [x] A2（R2）：同日重复活动总体只计一个安装；跨平台分别归属，总体仍去重；跨日长会话在再次输入后可观测。
- [x] A3（R2/R9）：回访样例、成熟时间和零分母表现符合定义；成功率及耗时样本口径可复现。
- [x] A4（R3/R9）：核心操作成功/失败/可观测取消正确，帮助、预览、无操作和内部嵌套不重复计数；强杀不伪造终态。
- [x] A5（R5/R11）：禁用、损坏状态、离线、超时、限频、并发发送时原输出和退出码不变；主进程不因遥测网络存活而等待。
- [x] A6（R7/R8/R12）：旧客户端继续工作，新统计只采用 v2 有效观测；缺少别名也能统计；管理员与普通用户权限正确。
- [x] A7（R10）：事件重试/并发重复不增计数，180 天清理不改变首次观测锚点；原有设备删除包含新事实与锚点。
- [x] A8（R2/R6/R7/R12）：面板四个区域可查询真实隔离测试数据；未成熟、零样本、时间异常或补传限制均可解释。

## Out Of Scope

- 任务流转与 Skill 调用统计留到后续批次。
- 不将活跃安装数等同于人数，不将会话观测等同于在线时长。
- 不采集提示词、对话、源码、项目路径、仓库地址或原始错误文本。
- 不采集宿主会话 ID、模型名称、token 消耗、外部 Plugin 身份或真实人数；这些不是本批指标所必需。
- 本次 Brief 的实施范围是两仓本地代码、迁移文件与验证；生产数据库执行、部署、发版和提交推送按各自流程另行执行。
