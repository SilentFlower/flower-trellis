# Brief — 放宽后台确认的 Git 快照、会话日志与材料预算

## Goal

- 让大仓库、长会话和较大的计划文件通过后台确认，同时保留对同一份计划的完整校验。

## Scope

- Git 整仓快照、计划文件指纹、Codex 与 Claude 会话记录读取。
- 材料、策略输出、状态和执行期限的预算与诊断。

## Non-Goals

- 原生 Windows 支持由后续子任务单独验证；发布和外部项目升级沿用独立流程。

## Technical Overview

- Git 输出和仅需指纹的文件分块算哈希；两端按文件身份和已核验位置增量读取会话记录。
- 拆分需要解析的材料、状态和各阶段的执行预算，保留完整展示、输入取消和到期复核。

## Context & Decisions

- `vibecoding-bench` 的整仓索引约 5.87 MiB，已触发 4 MiB 门槛。保留整仓校验范围，预算根据代表性负载实测调整。

## Risks

- 日志截断、替换或来源歧义时必须作废旧证据；进程超时必须回收，避免后台等待卡住。

## Acceptance

- 超过旧上限的索引、普通文件和会话记录可以通过核验；Git 状态或人工输入发生变化时，旧许可失效。
- 多仓验证记录耗时、尺寸和实际失败阶段；展示与领取期限独立验证。用户倒计时与单次领取语义保持一致。

## Next Step

- 先采集大仓库和多仓计划的只读基线。
