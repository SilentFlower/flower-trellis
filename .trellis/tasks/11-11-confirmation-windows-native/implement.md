# 原生 Windows 后台确认实施计划

1. 保存现有容量工作区的精确基线；创建隔离的 Windows 测试项目，采用纯测试动作并保留临时资源退出边界。
2. 先实测 Claude 的 Hook 载荷、Windows 命令参数、后台任务通知和退出事件；实现并验证原生路径、同会话双开及取消。
3. 用普通原生 Codex 窗口验证已有控制端点和精确线程队列，再接入本地代理与原窗口归属。验证 Windows 进程身份、监听端口、退出与 PID 复用。
4. 两端分别验证完整展示、倒计时、同会话唤醒、单次 claim/started，以及人工新消息、原窗口退出、恢复新窗口、双开和伪造通知。证据未闭合的宿主路径保留人工并登记缺口。
5. 运行原生 Windows Python 3.8/3.12 确认专项、Linux/WSL 原生确认回归与 `npm test`。核对安装和升级事务、资产投影、旧请求取消及容量基线差异。beta 发布保持暂停。
