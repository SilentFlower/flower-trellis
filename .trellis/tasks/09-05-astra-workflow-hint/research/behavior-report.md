# Astra SessionStart 行为对照报告

## 结论

六项预设行为指标在关闭/开启组均达到 5/5，主指标结论为 **无明显改善**：基线已经全部通过，当前样本无法量出进一步提升。没有观察到必读引用、planning 边界、已授权实施、纠错证据或普通简短问答的退化。

另有 **探索性模板遵循信号**：B4 完成实现后的 Check-All 报告，关闭组 0/5 使用完整分节结构，开启组 5/5 保留结果、维度表、自动修复、风险和下一步结构。该项是在阅读运行结果时发现的，未纳入预先冻结的 B4 主评分，不能作为预注册指标改善或长期稳定的证明。

开销上升：30 个开启场景共 206 个已完成工具项，关闭组为 150 个，增长 37.3%；主要集中于 B4。候选提示保持实验属性，不宣称彻底解决原始用户报告的问题。

## 固定条件与方法

- 日期：2026-09-05；客户端 codex-cli 0.153.4；模型输入固定 gpt-6-astra，reasoning effort=low。
- 英文块版本 1，1502 UTF-8 字节；SHA-256 为 36f590e030cdabefd15ec33266b93caf1ab969418b09f59d179a392a9cf0940e。
- 使用当前 CLI 正常 init 后的安装副本；每次复制到独立项目和新会话，六场景开关各 5 次，共 60 个场景、80 个用户轮次。B4/B5 第二轮通过 exec resume 恢复同一场景会话。
- 沿用同一用户 Provider 与权限配置；每次显式 workspace-write。隔离实验内关闭更新检查及 SubagentStart，保留真实 SessionStart 三段与 UserPromptSubmit。只为已审查的这些实验 Hook 使用单次 hook-trust 自动化参数，不更改持久信任或认证。
- 原生 model/source 由透明记录器捕获；不伪造事件或把候选正文塞进用户提示。开启组每场景只在初次 SessionStart 的 state 追加一块，关闭组零块；所有普通 UserPromptSubmit 均零新增，第二轮没有重复追加。
- 固定输入、六场景评分、隔离文件内容见 behavior-experiment.py 和 behavior-manifest.json；按重复序号交错开关顺序，最多 3 个独立客户端并发。
- 文件、完整展示、完整引用读取、任务状态与工具次数机械评分；B4 重复确认和 B5 证据回应逐一按真实记录复核。无退出非零或超时样本，没有丢弃失败样本。

全部场景累计 input tokens 为 4,669,531 / 4,959,691（+6.2%），output tokens 为 21,666 / 25,165（+16.2%）。input 含重复发送及可缓存上下文，不表示唯一上下文长度或计费金额。已从持久化 rollout 核对 exec resume 的 usage 是会话累计值；统计取最终累计快照，没有把第一轮重复相加。

B6 的 5 对独立问答均为 26,285 / 26,580 input tokens，稳定增量 295 tokens；这一数值只适用于本实验宿主/模型计量。工程新增正文块 1502 字节，加分隔换行后为 1503 字节。SessionStart-only 避免逐用户轮次新增副本，但已有提示仍可能随后续模型请求发送，并非后续调用完全没有成本。

B4 平均工具项 16.8 → 28.8（+71.4%），平均回复字符 1787.2 → 2420.6，既包含更多规则核对，也包含更完整的检查报告。B6 平均 77.4 → 81 字且零工具，没有变成长篇流程报告。

## 证据与限制

- behavior-evidence.jsonl.gz 保存全部 60 个结果的原始消息、完整工具输出、Hook 输入/输出、产物、会话编号和 usage；behavior-scores.json 保存逐次评分与档案哈希。原始逐轮 JSONL 和 stderr 同时保留在 .trellis-tmp/astra-behavior/，未将生产日志或认证配置打包。
- 固定的是可配置模型 slug、推理设置及客户端。当前 Provider 没有提供可锁定的 Astra 内部修订号或随机种子，无法保证服务端隐藏版本和采样完全一致。
- CLI 与本对话宿主的基础提示不保证相同；没有回放最初发生偏差的历史会话。因此不能把本次结果当作原问题的严格复现或彻底修复。
- 样本每组每场景仅 5 次，且预设场景基线已全部通过，有明显上限效应；语义复核没有盲化。探索性 Check-All 模板信号应在后续独立预设场景中复核，届时再决定是否增加具体门禁。
- 首版保持已规划的默认开启和独立关闭机制，未修改 Stop、UserPromptSubmit 或模型切换机制。没有因观察结果私自调参、替换模型或增加强制流程平台。
