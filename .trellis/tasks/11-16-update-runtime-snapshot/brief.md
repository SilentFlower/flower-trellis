# Brief — 修复升级快照误扫运行时目录

## Goal

- 让含运行时研究资料的项目正常升级，并保持失败补偿的数据边界。

## Scope

- 升级快照、沙箱、恢复和 Plugin 精确目标的扫描边界。
- 真实更新、回滚回归和对应规范；开发验收后续接新版 beta 发布。

## Non-Goals

- 业务项目实际升级、研究源码整理、Trellis 依赖升级及通用 Git ignore 策略。

## Technical Overview

- 在共用扫描层于遍历前排除默认运行时子树；显式 Plugin 目标继续精确备份与补偿，保留既有父目录和路径校验。

## Context & Decisions

- 隔离目录已复现 `.trellis/.runtime` 内研究软链阻断快照。
- 同版本 dry-run 与真实更新经过不同快照路径，需要覆盖实际执行。
- 沿用现有快照结构、CLI 参数和受管软链检查。运行状态由生命周期 owner 维护。

## Risks

- 排除目录与精确目标存在交叠，需要验证既有父目录、非目标资料和链接目标的保护。

## Acceptance

- 运行时资料正常通过真实升级、沙箱和补偿回归。
- 精确目标恢复旧内容和 mode，新增目标被正确清理，既有父目录保留。
- 近似目录名和受管软链边界回归通过。
- 本地完整回归及对应提交的原生 CI 通过，随后进入新版 beta 发版预览。

## Next Step

- 先补能够复现运行时研究软链阻断升级的回归。
