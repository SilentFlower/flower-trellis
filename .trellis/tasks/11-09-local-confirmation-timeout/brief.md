# Brief — 本项目后台确认演练

## Goal

- 在当前 Codex 中实现不阻塞对话的自定义后台计时，到期唤醒原会话，用户回复使旧等待失效。

## Scope

- 项目内试用命令、会话状态、原生事件订阅及队列唤醒。
- 请求只消费一次、旧提醒撤回、查询与取消。
- 本项目 Codex 使用说明、直接依赖声明及相关测试。

## Non-Goals

- 不自动接入 Brief、Check、Push 的业务默认动作，不发布或替换客户端。
- 不增加网页、窗口、MCP、输入 Hook 或启动包装器；本轮不制作原生二进制。

## Technical Overview

- 使用现有 Node 环境启动原生后台终端，主回合结束后开始计时。
- 后台订阅同一会话的用户消息；新回复使请求失效，到期则通过原生队列唤醒。
- 唤醒后先原子领取请求，核对会话、用户消息基线和状态，只有首次有效领取才能返回约定的演练文本。

## Context & Decisions

- 首版面向当前 Linux/WSL、Codex 0.167.0 managed daemon；订阅消息、唤醒和队列撤回已用真实客户端及本地模型替身验证。
- 原生队列不会按相同消息 ID 自动去重，去重由本地请求状态负责；`ws` 声明为直接依赖。

## Risks

- 已启动的过期模型回合无法撤回；保证旧请求不重复有效消费，不承诺竞态中零额外模型唤醒。
- 窗口关闭不等于会话关闭，不保证关窗立即取消；其它客户端与平台仍需另验。

## Acceptance

- 两个不同时长均能后台等待；期间主对话可继续输入，无人回复时到期唤醒原会话。
- 用户提前回复使旧等待失效；重复 worker、重复提醒和重复领取不重复执行演练默认动作。
- 到期与回复竞争、队列撤回、断连及回执未知均有明确结果，不向其它会话补投递。
- 新 Codex 可按本项目说明主动试用、查询和取消；现有人工确认流程不变。

## Next Step

- 确认后激活本任务，进入最小后台命令实现。
