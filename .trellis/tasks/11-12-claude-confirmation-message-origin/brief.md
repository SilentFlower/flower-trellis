# Brief — 统一 Claude 与 Codex 自动确认的会话读取边界

## Goal

- Claude 与 Codex 的自动确认只关注当前回合和本次等待期间的事件。

## Scope

- 调整 Claude 与 Codex 的会话记录读取边界，补上回归测试，同步本仓投影。

## Non-Goals

- 倒计时策略、授权流程和软件包发布保持现有安排。其他项目的安装另行处理。

## Technical Overview

- 两端准备时核对当前回合并记下位置。后台等待和领取从同一位置继续读取。
- 新的人工输入取消等待。到期只接受与本次请求、原生后台任务和当前回合相符的唤醒。

## Context & Decisions

- 原会话中的旧代理回传已经复现了准备失败。按本次确认划定读取范围，旧消息正文和来源不再作为准备条件。

## Risks

- Hook 与会话记录可能先后落盘。须覆盖准备期间收到新消息，以及后台进程重新打开记录的情况。

## Acceptance

- Claude 旧代理回传、仅落日志通知及 Codex 旧畸形事件均不会卡住准备。
- 新人工输入仍取消等待。粘贴通知文字按人工输入处理。旧通知和其他任务通知无法领取。
- 核对本仓源码与投影一致，并记录原会话只读回放结果。

## Next Step

- 启动任务后，实现按当前回合定位并继续读取，运行回归测试。
